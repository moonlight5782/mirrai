# MIRRAI Shopify theme block

`blocks/mirrai-ar.liquid` is the product-page theme app block. Add it to a Shopify theme extension, enter the MIRRAI Shop ID in the theme editor and place the block near the buy button. It reads the current variant SKU and refreshes the AR button when the variant changes.

A public Shopify App listing and OAuth installation still require a Shopify Partner account and app credentials; those cannot be created from the repository alone.
