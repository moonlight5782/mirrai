# MIRRAI + Hugging Face ZeroGPU

## 1. Подготовить аккаунт

Войдите на Hugging Face и подтвердите email. Бесплатное создание ZeroGPU Space доступно личным аккаунтам с хорошей репутацией; аккаунт обычно должен быть старше 30 дней.

## 2. Дублировать официальный Space

Откройте `https://huggingface.co/spaces/tencent/Hunyuan3D-2.1?duplicate=true` и выберите:

- имя: `mirrai-hunyuan3d`;
- видимость: Public;
- SDK: Gradio (сохраняется из исходного Space);
- Hardware: ZeroGPU;

Нажмите **Duplicate Space**. Первый запуск скачивает веса и может занять несколько минут.

## 3. Получить рабочий адрес

На странице созданного Space откройте меню **⋮ → Embed this Space**. Нужен прямой адрес вида:

`https://USERNAME-mirrai-hunyuan3d.hf.space`

## 4. Подключить MIRRAI

В настройках опубликованного MIRRAI добавьте переменную:

`HUGGINGFACE_SPACE_URL=https://USERNAME-mirrai-hunyuan3d.hf.space`

Для публичного бесплатного Space токен не требуется. Если позднее Space станет защищённым, добавьте секрет `HUGGINGFACE_TOKEN` с read-токеном Hugging Face.

## 5. Проверить

Откройте `/admin/catalog?shop=hugge-md`. Надпись должна измениться на «ZeroGPU или 3D-сервер подключён». Выберите один товар, нажмите **Добавить выбранные**, затем **Запустить / проверить**. После генерации GLB попадает в R2 со статусом **Нужна проверка** и не публикуется автоматически.

## Ограничения пилота

- Бесплатная квота ZeroGPU небольшая и очередь может ожидать GPU.
- Бесплатный Space и его исходники публичны.
- Для HUGGE сначала необходимо восстановить действительный HTTPS-сертификат магазина, иначе MIRRAI не сможет безопасно получить исходные фотографии.
- У Hunyuan3D 2.1 есть территориальные и коммерческие условия лицензии; перед обслуживанием магазинов из ЕС, Великобритании или Южной Кореи нужна отдельная проверка лицензии.
