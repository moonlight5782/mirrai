# MIRRAI — собственный сервер генерации 3D

Шлюз принимает фотографию товара, ставит генерацию в очередь Hunyuan3D 2.1 и возвращает готовый GLB для примерочной или AR.

## Сервер

- Ubuntu 22.04/24.04, NVIDIA Driver и NVIDIA Container Toolkit.
- Для формы требуется около 10 ГБ VRAM, для текстуры — около 21 ГБ; рекомендуется GPU с 24 ГБ VRAM или больше.
- 64 ГБ RAM, 100+ ГБ SSD и публичный HTTPS-домен, например `3d.example.com`.

## Запуск

1. Установите официальный Hunyuan3D 2.1 и запустите его API на порту `8081` с загруженными весами.
2. Задайте `ALLOWED_ORIGINS=https://адрес-сайта`.
3. В этом каталоге выполните `docker compose up -d --build`.
4. Опубликуйте порт 8000 через reverse proxy с TLS и проверьте `/health`.
5. Соберите сайт с `NEXT_PUBLIC_RECONSTRUCTION_API_URL=https://3d.example.com`.

Готовый GLB открывается сразу и не отправляется на генерацию. Фотографии распознаются автоматически. В режиме виджета (`?widget=1`) ручная загрузка скрыта: товар должен приходить со страницы магазина.

Текущая очередь рассчитана на один GPU и один процесс. Перед горизонтальным масштабированием состояние заданий следует перенести в Redis.
