# Проверка перед передачей разработчику — 3 октября 2026

## Объём

Рефакторинг ключевых клиентских файлов без редизайна: читаемый TSX в
`app/page.tsx` и `app/demo-store/store.tsx`, чистый модуль геометрии,
защита от продолжения устаревшей проверки после смены товара, исправление
повтора цвета в названии, комментарии об AR-ограничениях и руководство разработчика.
Это не заявление о завершённом рефакторинге всего репозитория.

## Проверки

- Node-тесты: авторизация, изоляция магазинов, лимитер, подписки, SDK,
  серверный HTML, геометрия и названия вариантов.
- Аудит размеров: все 16 локальных HUGGE GLB проходят проверку габаритов и пола.
- Python: два теста авторизации шлюза проходят.
- Публичный каталог: 16 опубликованных моделей; HEAD каждого GLB вернул HTTP 200.
  Это доступность файлов, не визуальный аудит всех моделей.
- Локальный браузер: каталог → Alba → следующая фотография → увеличенное фото →
  закрытие → 3D. Кресло отрисовалось, статус размеров — 62 × 86 × 90 см.
- Ширина 390 px: ширина документа 390, содержимого viewer 375;
  горизонтального переполнения документа нет. Это эмуляция ширины, не телефон.
- Brooke: смена серого на зелёный меняет SKU и открывает
  `/catalog/hugge-90157-trellis2-q8-pbr.glb`; проверка размеров — 58.5 × 59 × 88.5 см.
  В консоли проверенной вкладки ошибок не было.

## Важные различия окружений

Локальная база содержит 13 опубликованных моделей из 16; production — 16 из 16.
Остальные локальные статусы не изменялись для искусственного совпадения с production.
На этой Windows-установке dev-сервер доступен по `localhost:4177`, но не по
`127.0.0.1:4177`; используйте URL, который выводит сервер.

## Не подтверждено этим прогоном

- Камера, трекинг пола и фактическое размещение на iPhone/Android.
- Фотореалистичность и соответствие каждой модели физическому товару.
- Реальное списание денег и подключение внешних OAuth/GPU-сервисов.
- Полная ручная проверка всех административных экранов под каждой ролью.

Для выпуска используйте `npm run verify`, Python-тесты и ручной чек-лист
из [руководства разработчика](DEVELOPER_GUIDE_RU.md).
